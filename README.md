# ⚡ Pulse Messenger

Полноценный мессенджер с реальным временем, группами, каналами и ботами.
Работает на Python (Flask + Socket.IO), хранит данные в JSON файлах.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```
> Для длительности видео и более точных данных по аудио желательно (но не обязательно) установить `ffmpeg`/`ffprobe` в системе — без него длительность аудио всё ещё определяется через `mutagen`, а вот для видео тогда метаданные не извлекаются.


### 2. Запуск
```bash
python app.py
```

Откройте браузер: **http://localhost:8000**

## ✨ Функционал

### Аккаунт
- Регистрация: Имя, Фамилия, @username, пароль
- Уникальный 8-значный номер **#12345678** — генерируется автоматически
- Не привязан к Google, телефону или email
- JWT-токен сессии в localStorage

### Чаты
- **Личные сообщения (DM)** — найди пользователя по @username или #номеру
- **Группы** — создавай с участниками, покидай
- **Каналы** — публичные и приватные, владелец пишет → подписчики читают
- **Реальное время** через WebSocket (Socket.IO)

### Контакты
- Добавляй / удаляй контакты
- Поиск по имени, @username, #номеру

### UI
- 🌙 Тёмная / ☀️ Светлая тема
- 📱 Адаптивный мобильный интерфейс
- Ответ на сообщение (свайп/двойной клик)
- Индикатор печатания
- Эмодзи-панель

### Боты
- Создавай ботов с уникальным токеном
- Токен для интеграции через Pulse Bot API

### 🔐 Проверка файлов и метаданные
- При загрузке файл проверяется по **сигнатуре содержимого** (magic bytes), а не только по расширению — попытка выдать `.exe` за `.jpg` будет отклонена
- Текстовые форматы без сигнатуры (.txt/.csv) помечаются как `verified: null` (непроверяемые, но разрешённые)
- Автоматически извлекаются метаданные:
  - 🖼️ Изображения — размер (Ш×В), формат, EXIF (камера, дата съёмки и т.п.)
  - 📄 PDF — количество страниц, заголовок/автор
  - 🎵/🎬 Аудио/видео — длительность, разрешение видео (через `ffprobe`, если установлен)

### 📡 P2P-передача файлов
- Кнопка 📡 рядом с полем ввода (только в личных чатах с собеседником онлайн)
- Файл передаётся **напрямую между браузерами через WebRTC DataChannel** — сервер участвует только в сигналинге (SDP/ICE), как и при звонках, и никогда не получает и не хранит сами байты файла
- В истории чата сохраняется только отметка о факте передачи (имя/размер); скачать сам файл можно по ссылке, которая действует, пока открыта вкладка передачи — это ожидаемое ограничение настоящего P2P без сервера-посредника

## 🌐 Деплой на сервер

### HTTPS — теперь настраивается, а не зашит на чужой домен
Раньше путь к сертификату был жёстко прописан на `openmessenger.duckdns.org`. Теперь это переменные окружения:

```bash
export PULSE_DOMAIN=mychat.example.com        # ваш домен (только для вывода в консоль)
export PULSE_CERT_DIR=/etc/letsencrypt/live/mychat.example.com   # можно не задавать — вычислится из PULSE_DOMAIN
export PULSE_HTTPS_PORT=443                   # порт для HTTPS (443 требует root/setcap)
export PULSE_HTTP_PORT=8000                   # порт для HTTP-фолбэка, если сертификатов нет

python app.py
```

Если `fullchain.pem`/`privkey.pem` найдены — сервер поднимется на HTTPS, иначе автоматически откатится на обычный HTTP с понятным сообщением о том, чего не хватает.

### Heroku / Railway / Render
```bash
# Procfile
web: python app.py
```

### Nginx + Gunicorn
```bash
pip install gunicorn eventlet
gunicorn --worker-class eventlet -w 1 app:app --bind 0.0.0.0:8000
```

### Nginx конфиг (для WebSocket):
```nginx
location / {
    proxy_pass http://localhost:8000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
}
```

## 📱 Мобильное и 💻 десктопное «приложение»

Pulse теперь PWA (Progressive Web App): манифест (`static/manifest.json`) и service worker (`static/service-worker.js`) уже подключены в `templates/index.html`.

### Мобильное приложение — без сборки APK
Это тот же сайт, просто установленный как ярлык с иконкой на весь экран:
1. Открой сайт в браузере на телефоне
2. Chrome (Android): меню ⋮ → **«Установить приложение»** / «Добавить на главный экран»
   Safari (iOS): «Поделиться» → **«На экран “Домой”»**

### Настоящий APK/IPA (для публикации в маркете)
Через **Capacitor**:
```bash
npm install -g @capacitor/cli
npx cap init Pulse com.yourname.pulse
npx cap add android   # или: npx cap add ios
npx cap open android  # Android Studio → Build → Build APK
```

### Десктопное приложение (Windows/Mac/Linux)
Через **Electron**:
```bash
npm install -g electron electron-builder
```
`electron-main.js`:
```javascript
const { app, BrowserWindow } = require('electron');
function createWindow() {
  const win = new BrowserWindow({ width: 1200, height: 800 });
  win.loadURL('http://localhost:8000');
}
app.whenReady().then(createWindow);
```
Запуск: `electron electron-main.js`. Готовый `.exe`/`.dmg`: `electron-builder build`.

## 🪟 Быстрый запуск на Windows (без командной строки вручную)

В проекте есть готовые скрипты — просто дважды кликни файл в проводнике.

### `install_and_run.bat` — первый запуск / после обновления кода
- Сам находит Python, ставит все библиотеки из `requirements.txt`
- Запускает сервер в свёрнутом окне (видно на панели задач как "Pulse Server")
- Через пару секунд сам открывает `http://localhost:8000` в браузере
- Чтобы **остановить** сервер — просто закрой то свёрнутое окно

### `run_silent.vbs` — тихий запуск без чёрного окна
Используй, когда уже один раз всё поставил через `install_and_run.bat` и убедился,
что работает. Запускает сервер полностью в фоне (без консоли) и открывает страницу.
- Можно закинуть ярлык на этот файл в `Win+R → shell:startup`, чтобы Pulse
  поднимался сам при включении компьютера
- Остановить такой фоновый запуск — файлом `stop_pulse.bat`

### `stop_pulse.bat`
Останавливает сервер, если он был запущен через `run_silent.vbs` (когда закрыть
нечего — окна-то не видно).
